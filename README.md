# Inventory-Management-with-ML
This is a simple project that uses ML to inform the user of selling their high selling products and dead stock helping them keep track of the loading and unloading inventory according to volumes sold
The project also has bill generation to directly create a bill for the customer, graph analysis for tracking star products and least selling ones with a chart also comparing the percent of in demand products vs low selling ones, as well as a tracker to notify the owner of which stocks are needed urgently so the products arent out of stock
